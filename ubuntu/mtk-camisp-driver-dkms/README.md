# mtk-camisp-driver

Camera ISP 7 is a proprietary hardware in MediaTek SoC.

This repo is the out-of-tree kernel driver for Camera ISP 7 in MT8370/MT8390/MT8395 SoC.

## Branch

- `master`: Deprecated.
- `mtk-v5.15`: For kernel v5.15. The driver is compatible with [mtk-v5.15-dev](https://gitlab.com/mediatek/aiot/bsp/linux/-/tree/mtk-v5.15-dev).
